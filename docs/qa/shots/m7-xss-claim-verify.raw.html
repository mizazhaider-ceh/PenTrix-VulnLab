How to claim this flag
  1. Load this page fresh. A new one-time token is rendered into it as window.__px on every load.
  2. Run a payload that phones home to the collector with the page token (n='+window.__px). A token-less beacon is rejected.
  3. The flag is awarded and the scoreboard marks it captured. The widget below polls for confirmation.

Not getting the flag? Why beacons fail

Why beacons fail:
  • Token-less beacons are rejected (400). The collector requires n=window.__px. A plain alert(1) proves your payload executed, but it does not phone home, so no flag is awarded.
  • Tokens are single-use per page load. Each page load renders a fresh window.__px. A token from an earlier load cannot be replayed.
  • The beacon must carry data. An empty c= parameter is rejected. Exfiltrate something (e.g. document.cookie).
