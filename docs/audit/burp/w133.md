## json-csrf: JSON API CSRF via text/plain (simple request)

**Verdict:** BURP-CLEAN

**Tools old -> new:** `BZ, C` -> `BZ, B`

**Burp workflow steps:**
1. Set Burp as the browser proxy and sign in as alice (`/csrf/login/alice`).
2. Open `/csrf/json-email`, turn on Proxy intercept, and click "Fire the forged request".
3. Send the intercepted POST to Repeater; note the `Content-Type: text/plain` header and the `name=value` style body.
4. In Repeater, reshape the body so the first `name` line carries the JSON the API expects, then send with the victim's session cookie. The server mines the text/plain body for a JSON object and applies the email change, awarding the flag.

**Issues:** none blocking. The start field was a curl one-liner and the tool list put curl alongside Burp instead of the browser, which the challenge actually uses.

**Changes applied:**
- `tools` changed from `BZ, C` to `BZ, B`.
- `start` rewritten as a Burp-oriented starting point (proxy the browser, sign in as alice, capture the form submission).
- Third hint now names the Burp step (intercept in Proxy, rebuild in Repeater); still a nudge, no exploit pasted.
- `how` rewritten Burp-flavored: forge a cross-site email change with a simple request whose text/plain body carries the JSON the API expects.

## method-override-csrf: HTTP Method Override Smuggling (_method=DELETE)

**Verdict:** BURP-CLEAN

**Tools old -> new:** `BZ, C` -> `BZ, B`

**Burp workflow steps:**
1. Set Burp as the browser proxy and sign in as alice (`/csrf/login/alice`).
2. Open `/csrf/account`, turn on Proxy intercept, and submit the "Continue" form.
3. Send the intercepted plain POST to Repeater; note the `_method=DELETE` field in the body.
4. In Repeater, confirm the `_method` field names the privileged verb and send with the victim's session cookie. The server honors the override on the plain POST and runs the delete path, awarding the flag.

**Issues:** none blocking. Same as above: curl one-liner start and `C` in tools did not match the Burp-first flow.

**Changes applied:**
