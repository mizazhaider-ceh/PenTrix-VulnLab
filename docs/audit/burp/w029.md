Doctrine D16: every challenge fully solvable via Burp Suite (Proxy, Repeater, Intruder; Community enough). Voice is Burp-first, not curl-first.

## bypass (Blocklist bypass)

- Verdict: BURP-CLEAN
- Tools: C -> BZ, C
- Burp workflow: Browse to http://localhost:3000/ssrf/fetch2 through Burp Proxy, submit the Fetch a link form once with any URL, and send the request to Repeater. Confirm the blocklist rejects http://127.0.0.1:PORT/ssrf/internal/secret (403). Then, in Repeater, rewrite the url parameter host using an alternate loopback spelling (single decimal number, hex octets, or leading-zero octal octets) and send; the string check waves it through while the URL parser still delivers the request to loopback and the response body contains the internal secret marker, which awards the flag. For fuzzing, send the request to Intruder and attack the url parameter with a short payload list of alternate loopback spellings (Sniper is enough). The requireBypass guard in the challenge means the winning request must not contain the literal strings 127.0.0.1 or localhost.
- Issues: none. Plain GET requests with a URL-encoded query parameter; Burp Community Repeater and Intruder handle everything with no mangling. No raw sockets, no malformed HTTP, no timing dependency, no Burp-mangled bytes, no curl-specific behavior, no non-HTTP protocols. Note: the how copy lists 0.0.0.0 as an alternate spelling, but live testing showed 0.0.0.0 fails against /ssrf/fetch2 (that technique belongs to the separate zero-ip challenge); the how line was corrected to list only decimal, hex, and octal spellings.
- Changes applied: tools set to BZ, C (BZ first). start replaced the curl one-liner with a Burp Proxy plus Repeater starting point. hints rewritten to name the Burp steps (Intruder payload list for the url parameter, Repeater for testing spellings one at a time) as nudges only, no exploits pasted. how reworded to Burp-flavored fuzzing copy with no literal payload strings.
- Flagged for follow-up (not changed, outside the vuln-object scope): nothing. The challenge body already presents a Burp-neutral in-page form and the hint ladder carries no curl copy.
