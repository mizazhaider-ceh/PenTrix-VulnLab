- Burp workflow:
  1. In the browser with Burp Proxy on, open the FetchBox page (/ssrf#basic) and submit a harmless URL in the "Fetch a link" form. Watch the GET /ssrf/fetch request land in Proxy history; the response shows exactly what the server fetched.
  2. Right-click the intercepted GET /ssrf/fetch request and send it to Repeater.
  3. In Repeater, edit the url parameter so it points at the server's own loopback interface (127.0.0.1 on the lab port, the same port shown in the browser address bar) and at the internal secret path. Send the request. No URL-encoding tricks are needed; a plain loopback URL is accepted.
  4. Observe the response: the server-side fetched body contains the internal marker, and the page renders the flag box. The status endpoint (/ssrf/internal/status) renders but awards nothing, so aim at the secret path, not the status one.
  5. Optional: repeat with Intruder to confirm the response is stable, or compare a benign fetch against the loopback fetch to verify the difference.
