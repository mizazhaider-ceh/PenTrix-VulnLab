## put (Unauthenticated HTTP PUT)

- Verdict: BURP-CLEAN
- Tools: C -> BZ, C
- Burp workflow: Send any request to /misconfig/files/ to Repeater. Change the request line method to PUT, set the path to /misconfig/files/<yourname>.txt, add header Content-Type: text/plain, type a short text body in the message body area, and send (expect 201). Then browse to GET /misconfig/files/<yourname>.txt in the Burp browser to read it back; the readback awards the flag. Verb tampering is trivial in Repeater: the method line is editable directly.
- Issues: none. Plain well-formed HTTP PUT with a text body; Burp Community Repeater handles it with no mangling. The bad-upload path (non-buffer body) is not reachable through Burp since Repeater always sends a body correctly, which is fine: it is an error branch, not the exploit.
