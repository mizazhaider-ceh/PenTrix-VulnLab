## crypto/crypto-ecb-oracle

- Verdict: BURP-CLEAN
- Tools: "P, C" -> "BZ, P, C"
- Burp workflow:
  1. In the browser, open the vault page (/crypto/ecb) with Burp Proxy intercepting. Submit the form once with any printable prefix.
  2. Send the intercepted POST /crypto/ecb/encrypt request to Repeater.
  3. In Repeater, send a long run of one repeated byte via the inhex parameter and compare ciphertext blocks: identical plaintext blocks encrypt to identical ciphertext blocks, which confirms ECB and reveals the 16-byte block size.
  4. Using Repeater, craft a prefix that aligns the next unknown secret byte at the end of a block, then walk that byte through all 256 values and keep the one whose ciphertext block matches the target block. Repeat for each of the 28 secret bytes.
  5. Send the recovered secret to POST /crypto/ecb/solve to claim the flag. For speed, run the 256-value loop per byte through Intruder with Grep-Match on the target block; 28 bytes x 256 requests is routine Intruder traffic.

The oracle accepts hex-encoded input (inhex), so all bytes Burp sends are printable ASCII; nothing Burp would mangle.
