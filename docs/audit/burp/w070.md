## Challenge: alg-confusion (RS256 / HS256 Algorithm Confusion)

**Verdict: BURP-CLEAN**

**Tools:** old `N` -> new `BZ, N`

**Burp workflow steps:**
1. Configure the browser to proxy through Burp and open `/jwt/confusion`;
   read the mission brief and note the sample RS256 guest token.
2. Follow the RSA public key link (still through the proxy) and copy the PEM
   text from `/jwt/confusion-pubkey`, including the trailing newline.
3. Mint an HS256 token with `role: "admin"` signed with HMAC using the PEM
   bytes as the secret. This is the one step that needs a real crypto
   operation, so the sanctioned node/jwt helper (N) is used here; a Burp JWT
   Editor BApp install can also sign HS256 with a custom secret inside
   Repeater for a no-shell route. Base64url-editing alone in Burp Decoder
   cannot produce a valid HMAC, so Decoder is for inspection only.
4. Find the POST `/jwt/confusion` in Proxy history, send it to Repeater,
   replace the `token` form field with the forged token (base64url, fully
   ASCII, passes through Repeater untouched), and send. The response renders
   the admin panel with the flag block.

**Issues:** none. The whole chain is standard HTTP: two GETs and one
urlencoded POST with an ASCII-only token. No raw sockets, no malformed HTTP,
no Burp-mangled bytes (the JWT alphabet needs no encoding, and the PEM
trailing newline only matters for the local signing helper, not for what
travels in the request), and no curl-specific behavior. The N helper is kept
because HMAC minting genuinely needs computation; everything the user touches
over the wire is pure Proxy/Repeater.

**Changes applied:**
- `tools`: `N` -> `BZ, N` (Burp first; node/jwt kept as the token-minting helper).
- `start`: replaced the curl one-liner with a Burp-oriented starting point
  (proxy the browser, open the challenge, copy the PEM, mint the token, paste
  it into the form or replay the POST in Repeater).
- `hint`/`hints`: rewritten to name the Burp steps (Proxy, Decoder for
  inspection, Repeater for the token field); nudges only, no pasted exploits.
- `how`: Burp-flavored (fetch the pubkey, mint with its bytes, submit via the
  form or a Repeater POST to `/jwt/confusion`).
