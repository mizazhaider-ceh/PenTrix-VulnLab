2. Submit one comment through the form, or send the sign-guestbook POST to Repeater. In Repeater, set the body field to a script that beacons to /xss/collect with c, v=stored and n=window.__px. The POST is a plain application/x-www-form-urlencoded request; the server answers 302.
3. Reload /xss/guestbook in the proxied browser. The stored comment renders raw, the script runs in the page, and Burp Proxy history shows the beacon GET to /xss/collect returning 200.
4. Check /xss/claim-status?v=stored (the claim widget polls this) to confirm the flag was awarded.
