## lfi/log-poison (Log Poisoning Chain)
- Verdict: BURP-CLEAN
- Tools: "C" -> "BZ, C"
- Burp workflow:
  1. Browse to /lfi/log-demo with Burp Proxy intercept on and forward the request, then send it to Repeater (right-click, Send to Repeater, or Ctrl+R).
  2. In Repeater, edit the `User-Agent` header to a recognizable marker string and send. This poisons the server's access log, which records the raw User-Agent (header editing is trivial in Repeater; no raw sockets needed).
  3. Open a new Repeater tab on the document viewer (/lfi/view) and request the access log with a traversal payload. The response includes the poisoned log line, and the flag awards automatically when the marker appears in the returned file.
  4. Note the chain is synchronous: the log append completes inside step 2's request, so there is no race or timing window to worry about, and the marker is plain ASCII that Burp never mangles.
