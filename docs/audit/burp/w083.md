## Burp workflow steps
1. Start Burp Suite Community, configure the browser to use it as proxy, and open
   the PenTrix Store checkout page at /bizlogic/currency.
2. Submit the "Pay $50" form with Proxy Intercept on. Forward the request, then find
   the POST to /bizlogic/currency/pay in Proxy HTTP history and send it to Repeater.
3. In Repeater, replay the request with the currency parameter changed to a
   low-value currency label (the amount stays 50). Read the receipt on the response:
   the $50 USD order settles for about $0.34 and the flag appears on the page.
4. Intruder is optional here; this is a single manual Repeater shot, not a
   brute-force or encoding case.

## Issues
None found. The exploit is a plain application/x-www-form-urlencoded POST with a
tampered parameter, exactly the kind of traffic Burp Proxy and Repeater handle
natively. No raw sockets, malformed HTTP, Burp-mangled bytes, or curl-specific
behavior involved. The only Burp-hostile bits were copy-level: the `start` field
was a curl one-liner and the page body contained a curl example.
