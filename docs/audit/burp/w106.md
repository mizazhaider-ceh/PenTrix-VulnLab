## Live verification (scratch server, fresh DB, coordinator-run)
- proto-query: fresh server, GET /proto/query/admin with no pollution returns
  the access-denied page and NO flag (cheat rejected). GET
  /proto/query?__proto__[role]=admin returns 200; subsequent GET
  /proto/query/admin awards the flag (real exploit works). Note: curl needs
  -g for the bracketed query string; Burp Repeater sends it as-is.
- proto-unicode-bypass: POST /proto/unicode/merge with Content-Type:
  text/plain and a JSON body using \u005f escapes returns 200; GET
  /proto/unicode/admin awards the flag (real exploit works).
- Note: prototype pollution is process-global in Node, so verifying the cheat
  case requires a fresh server boot (done for proto-query). The per-challenge
  tests in tests/proto.test.js cover the cheat cases against fresh instances.

## Burp workflow
1. Proxy the browser through Burp and open the challenge console
   (/proto/query or /proto/unicode).
2. Send the merge request to Repeater (Ctrl+R). For proto-query, edit the
   query string; for proto-unicode-bypass, POST to /proto/unicode/merge with
   Content-Type: text/plain and the escaped JSON body.
3. Reload the admin check (/proto/query/admin or /proto/unicode/admin) in the
   proxied browser. A polluted prototype makes the fresh {} read role=admin
   and the flag is awarded.
