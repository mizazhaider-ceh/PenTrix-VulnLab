### Burp workflow steps
1. Point the browser at Burp (Proxy on), load `/xss/search`, and submit a normal search.
2. Find the GET to `/xss/search` in Proxy history and send it to Repeater.
3. In Repeater, reshape the `q` parameter into a `<script>` tag that fires the beacon pattern shown in the claim box (`/xss/collect` with the page token `window.__px` as `n`). The page token is readable from the rendered page source in the Burp browser.

The whole chain is standard HTTP: one reflected GET whose response carries the payload, then a plain GET beacon to `/xss/collect`. No raw sockets, no malformed HTTP, no timing tricks, no curl-only behavior, and the Community edition is enough.
