- Verdict: BURP-CLEAN
- Tools: "B" -> "BZ, B"
- Burp workflow:
  1. In the browser (with Burp Proxy as the proxy), open the widget page (/proto/dos). Find the GET /proto/dos request in Burp's Proxy history.
  2. Right-click that request and send it to Repeater.
  3. In Repeater, add a polluted query parameter that targets __proto__[toString] with a non-function value, then send the request.
  4. Observe the response: the server renders "The widget broke" and the crash page, because string coercion (`${widget}`) can no longer call toString(). The crash page carries the flag box. The pollution is per-request, so a plain reload in the browser shows a fresh widget.
