# Burp-first audit w040: Ping Gadget (no filtering) (cmdi/basic)

## Verdict

**BURP-CLEAN.** The full exploit chain runs over plain HTTP GET through Proxy and Repeater with no special tooling: capture the ping form request, send it to Repeater, edit the `host` query parameter with a command separator, and read the response body. No raw sockets, no malformed HTTP, no timing tricks, no bytes Burp mangles, no non-HTTP protocol. Standard Community tooling is enough.

## Tools

- Old: `B, C` (Browser, curl)
- New: `BZ, B` (Burp/ZAP first, Browser kept for loading the gadget)

BZ goes first because the entire solve is Proxy-to-Repeater query parameter editing.

## Burp workflow steps

1. Open the ping gadget in Burp's browser with Proxy on and submit a plain host like `127.0.0.1`.
2. In Proxy history, find the GET request to `/cmdi/ping` and send it to Repeater.
3. In Repeater, edit the `host` parameter value: keep a valid host, then type a command separator and a second command. Burp URL-encodes the metacharacters for you.
4. Send the request and read the response body. The flag fires only when the second command's real output appears in the rendered command output, so pick a command that prints something unmistakable.

## Issues

- Tooling was curl-first (`tools: 'B, C'`, `start` was a curl one-liner, `how` showed a curl-style query), which fights D16's Burp-first voice.
- Hints named the trick but not the Burp step; the ladder now names Proxy capture and Repeater editing as nudges without pasting exploits.
- No functional blocker: the gadget is a GET form, parameters stay intact through Burp, and `executedSomething` only rewards genuine command output, so the flag bar and flag secrecy are unchanged.

## Changes applied

- `tools`: `B, C` -> `BZ, B`.
- `start`: now Burp-oriented (Proxy on, submit a plain host, push to Repeater); no curl one-liner.
- `hints`: three nudges naming the Burp steps (find request in Proxy history, send to Repeater, edit the `host` value and read the response body); no exploit pasted.
- `how`: Burp-flavored, tool-neutral on the exact separator so the learner discovers it.
- Verified: `node --check` passes, diff has zero em dashes, scratch boot (DB_PATH=/tmp/burp-w040.db, PORT=18040) returned HTTP 200 for `/cmdi/ping`, server killed after.
- No redesign needed; challenge file, flag bar, and flag secrecy untouched.
