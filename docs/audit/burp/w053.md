# Burp Audit w053: upload-case (Case-sensitive blacklist bypass)

## Verdict: BURP-CLEAN

## Challenge
- Module: upload, challenge `upload-case`
- Route: `POST /upload/ext-blacklist?filename=...` with raw request body
- Vuln: the extension blacklist (`.svg`, `.html`, `.htm`) compares the final extension case-sensitively via `path.extname` (no lowercasing). A case variant such as `evil.SVG` misses the blacklist entry but is still served as active SVG at `/upload/view/:name`, awarding the flag.

## Tools old -> new
- old: `C` (curl)
- new: `BZ` (Burp/ZAP)

## Burp workflow steps
1. In Burp Proxy, browse to the upload module (`/upload#upload-case`) with the browser proxying through Burp.
2. Use the upload form and intercept the resulting POST to `/upload/ext-blacklist?filename=...` in the Proxy (or intercept any request to that endpoint).
3. Right-click the intercepted request and send it to Repeater.
4. In Repeater, change only the case of the `filename` query parameter extension (for example, a blocked lowercase extension becomes its uppercase variant), keeping the body as valid SVG content.
5. Send the request. The 200 response shows the file stored, and following the returned `/upload/view/...` link renders it as active content, with the flag box and fix panel on the response page.

## Issues
- None found. The exploit chain needs only standard HTTP: one POST with a query parameter and a body. No raw sockets, no malformed HTTP that Burp normalizes, no bytes Burp mangles, no curl-only behavior, no non-HTTP protocol.
- The audit rule about reading quiz-graded flags from raw terminal output (not screenshots) is respected: the flag is awarded in the HTTP response body of the upload POST, fully visible in Repeater.

## Changes applied
File: `modules/upload/challenges/upload-case.js` (vuln object only, router logic untouched).
- `tools`: `C` -> `BZ` (Burp/ZAP first, only tool).
- `start`: replaced the curl one-liner with a Burp-oriented starting point: proxy the site, intercept the upload request, send it to Repeater.
- `hints`: first hint now names the Burp step (intercept in Proxy, forward to Repeater, change only the extension case). Nudges only, no exploit pasted.
- `how`: Burp-flavored: intercept the upload POST, send to Repeater, change the filename case to a blocked-extension variant; the `.svg` entry misses it and the file is served as active content.
