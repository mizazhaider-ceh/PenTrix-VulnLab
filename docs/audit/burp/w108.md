# Burp Audit: cors-null (w108)

## Verdict
BURP-CLEAN. The whole exploit chain is standard HTTP and works in Burp Suite Community with Proxy and Repeater. The server checks `req.headers.origin === 'null'`, and typing a literal `Origin: null` header in Repeater is exactly the request the test suite sends, so Burp, curl and the `/cors/prove` check all hit the same code path.

## Tools old -> new
Old: `B`
New: `BZ, B` (Burp/ZAP now listed first per D16; browser stays as an alternative for the real cross-origin proof)

## Burp workflow steps
1. Proxy the browser, visit `/cors/null-origin`, and send the `GET /cors/api/settings` request to Repeater.
2. In Repeater, add the header `Origin: null` (type the word `null` literally, no quotes) and send.
3. Read the response headers: `Access-Control-Allow-Origin: null` plus `Access-Control-Allow-Credentials: true` proves the null origin is trusted with credentials. Other values, e.g. `Origin: https://evil.com`, earn no CORS headers at all.
4. In the Burp proxy browser, open `/cors/prove?vuln=cors-null&origin=null`. The page shows the real response headers the server sent for that Origin and awards the flag when the trusted combination is confirmed.

## Issues
None. No raw sockets, no Burp-mangled bytes, no curl-only behavior: the flag comes from `/cors/prove` inspecting plain response headers, and the vulnerable endpoint is a plain JSON GET. The challenge page still shows a curl "Try it raw" payload block as reference, which is fine as a second option now that the Burp path is primary.

## Changes applied
- `tools`: `B` -> `BZ, B`, Burp/ZAP first per D16.
- `start`: replaced the curl one-liner with a Repeater-oriented starting point (send GET /cors/api/settings with a literal Origin: null header and read the response headers).
- `hints`: ladder rewritten to name the Burp step at each level (add the Origin header in Repeater and watch the response headers, the string null is the winning value, then collect the flag through /cors/prove). Nudges only, no exploit pasted.
- `how`: Burp-flavored (open the prove URL in the Burp proxy browser; the header check awards the flag).
