## Challenge 1: race-upload-scan (Beat the AV Scan, TOCTOU)

**Verdict:** CLEAN. Fully solvable with Burp Suite Community Proxy + Repeater.
The 2-second window is generous, and there is no async gap to beat, so the
test's sequential upload-then-fetch pattern maps directly to a manual
Proxy capture followed by a Repeater fetch. No raw-socket tricks involved.

**Tools:** old `P, C` -> new `BZ, B`. Browser or Burp Repeater is enough; the
Python timing loop was misleading.

**Burp workflow steps:**
1. Run Burp Proxy, open the vault upload form in the browser, submit a file.
2. In Proxy history, note the uploaded filename and the fetch URL
   `/race/files/<name>`.
3. Send the upload POST to Repeater for a clean, fast replay if needed, and
   fetch the file URL in Repeater within the 2-second scan window.
4. A 200 response with the file content means the scan was beaten and the
   flag is awarded.

**Issues:** start used a curl one-liner; tools did not name Burp; hints did
not name the Burp step; how was tool-neutral instead of Burp-flavored.

**Changes applied:** vuln.tools now `BZ, B`; vuln.start names Burp Proxy and
Burp Repeater; hints rewritten to name the Proxy capture and Repeater fetch
as nudges, without pasting any exploit; vuln.how is now Burp-flavored.

## Challenge 2: race-vote (Vote Counted Twice)

**Verdict:** CLEAN. Fully solvable with Burp Suite Community Intruder in
parallel mode. The duplicate check and the insert are separated by an async
sleep, so a burst of concurrent votes for the same name both pass the check.
The test uses plain parallel POSTs (burstN, 6 concurrent), no raw-socket
tricks, which is exactly what Intruder's concurrent requests do.

**Tools:** old `P, C` -> new `BZ, C`. Burp Intruder is the primary tool.

**Burp workflow steps:**
1. Run Burp Proxy, vote once in the browser with a chosen name.
2. In Proxy history, send the vote POST to Intruder.
3. Set several concurrent threads and replay the identical vote request in
   parallel (null or single payload position, same name each time).
4. Open the poll results: the same name counted more than once proves the
   duplicate check lost the race, and the flag is awarded.

**Issues:** start used a curl + xargs one-liner; tools did not name Burp;
hints did not name the Intruder step; how was tool-neutral instead of
Burp-flavored.

**Changes applied:** vuln.tools now `BZ, C`; vuln.start names Burp Proxy and
Burp Intruder firing a burst of concurrent identical votes; hints rewritten
to name the Proxy capture, Intruder parallel mode, and the results-table
check as nudges, without pasting any exploit; vuln.how is now Burp-flavored.
