# Burp audit w045: cmdi-wildcard (Ping Gadget v7)

## Verdict
BURP-CLEAN. The exploit chain is a single plain GET request to /cmdi/ping7 with the injection in the host query parameter. Burp Proxy, Repeater, and Intruder all handle this natively with standard HTTP. No raw sockets, malformed HTTP, timing tricks, non-HTTP protocols, or Burp-mangled bytes anywhere in the chain.

## Tools old -> new
- Old: B, C (Browser, curl)
- New: BZ, B, C (Burp/ZAP, Browser, curl)

BZ moved first per the Burp-first doctrine. Browser and curl remain because the payload also works from an address bar and a one-liner, but Burp Repeater is the intended way to work through the mutations.

## Burp workflow steps
1. In Burp Suite, set the browser proxy and browse to the Ping Gadget v7 page (/cmdi/ping7). Submit a baseline ping of 127.0.0.1 and forward the request.
2. Send the request to Repeater (Ctrl+R / Cmd+R). The host query parameter is the injection point.
3. In Repeater, try a baseline bypass probe, for example host=127.0.0.1;id. Read the ping output in the response to see what the filter echoes back and what it strips.
4. Confirm the block: host=127.0.0.1;cat /etc/passwd returns no file content, showing the word cat and standalone / are stripped.
5. Reason about the filter order: the blacklist runs on the raw string, but the shell expands ? globs only when the command executes. Build a pattern with one ? per letter so neither banned token ever appears literally.
6. In Repeater, rebuild the command name and the /etc/passwd path with ? placeholders, chained after the ping with a statement separator, and send. The response contains the passwd content and the flag is awarded. Intruder can automate the placeholder-length guessing if you want to fuzz the ? counts instead.

## Issues
- None found for Burp compatibility. The award check (host contains ? and the output matches passwd evidence) depends only on the decoded query string, which Burp Repeater passes through exactly. Tested with both URL-encoded and raw ? forms.
- Pre-audit metadata issue: tools listed curl but Burp was the natural fit, and start was a curl one-liner. Fixed in this pass.
