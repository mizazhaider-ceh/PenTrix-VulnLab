# Burp-first audit: w112 redirect-data (data: Scheme Honored)

## Verdict

BURP-CLEAN. The full exploit chain works through Burp Suite Community with Proxy
and Repeater only, using standard HTTP GET requests. No raw sockets, no
Burp-mangled bytes, no curl-specific behavior, no non-HTTP protocol.

## Challenge

`modules/redirect/challenges/redirect-data.js`. GET `/redirect/data?next=<target>`
responds 302 and reflects the raw `next` value into the `Location` header with no
scheme allowlist. When the target starts with `data:` (case-insensitive), the
server awards the flag and renders it in the 302 response body. Test coverage in
`tests/redirect.test.js` asserts 302 status, the `data:` scheme in the Location
header, flag presence in the body for `data:text/html,...` targets, and that
plain `https://` targets award nothing.

## Tools old -> new

- Old: `C` (curl)
- New: `BZ, B` (Burp/ZAP first, browser kept for the entry form and proxying)

## Burp workflow steps

1. In your browser with Burp Proxy on, open `/redirect/data` and submit the
   destination form once so the GET request lands in Proxy HTTP history.
2. Forward the request to Repeater.
3. In Repeater, change the `next` parameter value to a URL-encoded
   `data:text/html` document and send.
4. Read the response: the 302 `Location` header echoes the `data:` URL, and the
   response body contains the flag, because the server honors any scheme.
5. Repeater lets you iterate schemes (`javascript:`, protocol-relative, plain
   `https:`) to confirm which ones the server refuses versus honors.

## Issues

- None blocking. The payload is plain ASCII URL-encoded text, which Burp
  transmits without mangling. The flag appears server-side in the 302 body, so
  no browser navigation or beacon step is needed. Repeater is a natural fit
  because the challenge is pure request/response header inspection.

- `hints`: rewrote as three Burp-step nudges (proxy then Repeater; iterate
  schemes; read Location header and body). No exploit pasted.
- `how`: Burp-flavored description of the 302 plus flag-in-body flow.
