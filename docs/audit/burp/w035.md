# Burp-first audit: w035, lfi/config-read (Secret Config Read)

## Verdict
BURP-CLEAN. The exploit chain is a plain HTTP GET whose only moving part is
the `file` query parameter, which the server applies with zero validation.
Proxy captures the Read config form submission, Repeater edits the `file`
parameter, and the response renders the planted config with the flag. This is
exactly the Proxy plus Repeater shape Community Edition handles natively.

## Tools: old -> new
- Old: `B`
- New: `BZ, B`

Burp/ZAP moves to first position under the Burp-first doctrine (D16): the
whole chain is request tampering on one query parameter, which is Repeater's
core job. The browser tag stays because the lab page is browser-rendered and
the form is the natural entry point. Nothing in the chain needs curl, so the
curl tag is gone.

## Burp workflow steps
1. Proxy: start Burp Proxy, browse to `/lfi/config`, and submit the Read
   config form once (the default `readme.txt` read). The GET request with the
   `file` parameter lands in the HTTP history.
2. Repeater: send that request to Repeater (Ctrl+R). Change the `file`
   parameter from the benign default to a path that climbs one level out of
   `docs/`, then send.
3. Read the response: the page renders the file contents. When the planted
   config one directory above `docs/` is reached, its contents include the
   marker and the page awards the flag automatically.
4. Optional Intruder: mark the `file` parameter as a payload position and
   fuzz traversal shapes (`../`, `..%2F`, deeper climbs) if you want to
   practice LFI enumeration quickly. A Sniper attack on the single parameter
   is enough; no special payload processing is needed.

## Issues
None found. Plain HTTP GET through a standard query parameter: no raw socket
control, no malformed HTTP that Burp would normalize, no timing sensitivity,
no byte-exact payloads Burp would mangle. URL-encoded traversal
(`..%2F`) survives Proxy, Repeater, and Intruder unchanged, and Express
decodes it server-side, so Burp's normalization cannot break the chain.
